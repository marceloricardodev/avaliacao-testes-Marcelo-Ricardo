Projeto desenvolvido em Java com o objetivo de aplicar conceitos de Git, GitHub e testes unitários utilizando JUnit.

A aplicação consiste em uma calculadora simples com as operações de soma e divisão. Foram criados testes para validar o funcionamento correto das operações e o tratamento de erro em divisões por zero.

O projeto foi versionado utilizando Git, com desenvolvimento dos testes na branch plano-testes e posterior integração à branch main.

Tecnologias utilizadas:

* Java
* JUnit 5
* Git
* GitHub
* IntelliJ IDEA
